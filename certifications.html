Comment ajouter une certification

1. Dépose ton fichier PDF dans le dossier de ton repo GitHub (ex: certifs/nom-certif.pdf)
2. Dans ce fichier certifications.html, duplique une carte existante et modifie le nom, la description et le lien PDF
3. Pousse les modifications sur GitHub — Netlify redéploie automatiquement
